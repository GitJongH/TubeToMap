# TubeToMap

[English](README.en.md)

유튜브 영상 **설명란에 적힌 구글 지도 링크**를 내 **구글 지도 목록**에 한 번에 저장하는 Chrome 확장 프로그램이에요. 맛집·여행 영상에서 장소를 하나씩 열어 저장하던 일을 버튼 한 번으로 줄여 줘요.

- 설명란의 지도 링크를 찾아 장소 이름과 함께 보여 줘요. 저장할 장소는 체크로 고를 수 있어요.
- 내 구글 지도 목록 중 하나를 고르거나, 새 목록을 만들어 거기에 저장해요.
- 각 장소 **메모에 영상 제목과 주소**를 남겨서, 나중에 "이 장소를 왜 저장했는지" 알 수 있어요.
- 일부가 실패하면 실패한 장소만 다시 시도하고, 끝나면 구글 지도에서 결과를 바로 열어 볼 수 있어요.

> **참고** 구글 지도에는 목록용 공식 API가 없어서, 로그인된 내 브라우저의 구글 지도 화면을 자동으로 조작해요. TubeToMap은 구글·유튜브와 관련이 없는 비공식 도구예요.

## 설치

1. 이 저장소를 내려받아요(Code → Download ZIP 후 압축 해제, 또는 `git clone`).
2. Chrome에서 `chrome://extensions`를 열고 오른쪽 위 **개발자 모드**를 켜요.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 이 폴더를 선택해요.
4. 같은 Chrome에서 Google 계정으로 구글 지도에 로그인해 둬요.

요구 사항: Chrome 114 이상(사이드 패널 지원), 구글 지도 화면 언어는 **한국어 또는 영어**.

## 사용

1. 유튜브 영상 페이지에서 TubeToMap 아이콘을 눌러 **사이드 패널**을 열어요. 다른 영상으로 이동하면 그 영상 기준으로 다시 읽어요.
2. 처음에는 내 구글 지도 목록을 자동으로 불러와요. **저장할 목록**을 고르거나 **새 목록 이름**을 적고 만들기를 눌러요.
   - 각 장소 오른쪽의 ↗ 아이콘을 누르면 그 장소를 구글 지도에서 바로 열어 볼 수 있어요.
3. 저장할 장소를 체크하고 **N곳 저장**을 눌러요. 저장하는 동안 남은 시간이 표시되고, **멈추기**를 누르면 지금 장소까지만 마치고 멈춰요. 멈춘 뒤에는 **남은 N곳 이어서 저장**으로 계속할 수 있어요.
4. 각 장소 메모에 `YouTube: <영상 제목> <영상 주소>`가 들어가요. 이미 메모가 있으면 아래 줄에 덧붙이고, 이미 목록에 있는 장소는 "이미 있음"으로 표시하고 메모만 추가해요.
5. 끝나면 **지도에서 결과 확인**을 눌러 구글 지도에서 확인해요. 실패한 장소는 **실패 N곳 다시 시도**로 이어서 처리해요.

저장하는 동안 구글 지도 창이 잠깐 열렸다 닫히고, Chrome 상단에 "디버깅 중" 안내가 뜨는 건 정상이에요(아래 개인정보 참고).

## 개인정보와 권한

- 개발자나 제3자의 서버로 **어떤 데이터도 보내지 않아요.** 분석 도구도 없어요. 자세한 내용은 [PRIVACY.md](PRIVACY.md)를 봐 주세요.
- `debugger` 권한은 지도 작업 창에 포커스가 없어도 글자 입력과 메모 저장이 되도록 "포커스 있음" 상태를 흉내 내는 데만 써요(`Emulation.setFocusEmulationEnabled` 한 가지 명령). 이 권한 때문에 작업 중 "디버깅 중" 안내가 떠요.

### 설치할 때 보이는 경고

Chrome은 확장 프로그램을 설치할 때 권한 경고를 보여 줘요. TubeToMap에서는 아래가 뜨고, 이유와 실제로 하는 일은 이래요.

| Chrome이 보여 주는 경고 | 이유 |
|---|---|
| **Access the page debugger backend**<br>**Read and change all your data on all websites** (`debugger` 권한) | 지도 작업 창에 포커스가 없어도 글자 입력과 메모 저장이 되게 하려고 필요해요. 아래 설명을 봐 주세요. |
| Read your browsing history (`tabs` 권한) | 현재 탭이 유튜브 영상인지, 지도 작업 창이 열렸는지 확인하려고 필요해요. 탭 주소를 읽을 뿐 방문 기록을 저장하거나 보내지 않아요. |
| Read and change your data on youtube.com / google.com | 영상 설명란을 읽고, 구글 지도 화면에서 목록을 읽고 장소를 저장하려고 필요해요. |

**`debugger` 권한이 하는 일은 한 가지예요.** 저장하는 동안 열리는 **구글 지도 작업 창의 탭 하나**에만 연결해서 `Emulation.setFocusEmulationEnabled` 명령 한 개를 보내요. 페이지가 "포커스가 있다"고 믿게 만드는 명령이고, 페이지 내용을 읽거나 다른 탭을 건드리지 않아요. 작업이 끝나면 연결을 해제하고 창을 닫아요. 코드는 `background.js`의 `emulateFocus`와 `closeWork`에서 확인할 수 있어요. 작업 중 Chrome 상단에 뜨는 "디버깅 중" 안내는 이 연결 때문이에요.

이 방식이 마음에 걸리면 설치하지 않으셔도 돼요. 소스가 모두 공개돼 있어서 직접 읽어 보고 판단할 수 있어요.

## 알려진 한계

- 구글 지도 **한국어/영어 화면**만 지원해요(영어는 `?hl=en` 화면에서 확인). 다른 언어는 `lib/ui.js`의 문구 표에 추가하면 돼요.
- 확장 프로그램 화면은 **한국어/영어**를 지원하고 브라우저 언어를 따라가요(그 밖의 언어는 영어). 새 언어는 `_locales/en/messages.json`을 복사해 번역해 넣으면 돼요(`npm test`가 빠진 키를 알려 줘요).
- 지도 도메인은 `google.com` / `google.co.kr`만 지원하고, 기본 로그인 계정 하나만 가정해요.
- 새로 만든 목록은 장소 페이지의 저장 창에 몇 초 늦게 나타날 수 있어, 이 경우 자동으로 한 번 더 시도해요.
- 구글이 화면을 바꾸면 동작이 깨질 수 있어요. 그럴 때는 아래 "문제 신고"를 이용해 주세요.
- 장소를 한꺼번에 많이 저장하면 시간이 걸려요(장소 사이에 1.5초 간격을 둬요). 개인이 쓰는 정도의 소량 사용을 기준으로 만들었어요.

## 문제 신고

패널에 **"구글 지도 화면이 바뀐 것 같아요"**가 나오면 **진단 정보 복사** 버튼을 눌러, 복사한 내용을 [이슈](../../issues/new/choose)에 붙여 알려 주세요. 진단 정보에는 오류 코드, 화면 언어, 버전, 브라우저 정보만 들어 있고 개인 정보는 없어요. 새 화면 언어 지원 요청도 이슈로 받아요.

## 개발

의존성 없이 순수 JavaScript로 만들어서 빌드 단계가 없어요. 코드를 고친 뒤에는 `chrome://extensions`에서 확장 프로그램의 새로고침(↻)을 눌러요.

```
manifest.json      확장 프로그램 설정(Manifest V3)
background.js      서비스 워커: 지도 작업 창을 열어 장소를 순차 처리, 진행 상태 기록
content/maps.js    구글 지도 화면 조작(목록 읽기, 새 목록, 장소 저장, 메모)
lib/ui.js          구글 지도 화면 문구(한국어/영어)와 판별 함수 ← 구글이 화면을 바꾸면 여기부터 고쳐요
lib/parse.js       설명란에서 장소 이름과 지도 링크를 뽑는 함수
lib/eta.js         저장 작업의 남은 시간 추정
_locales/          확장 프로그램 화면 문구(en, ko)
popup/             사이드 패널 UI(파일 이름만 popup)
icons/             아이콘
test/              단위 테스트
```

```
npm test        # 또는: node --test test/parse.test.js test/ui.test.js test/eta.test.js test/i18n.test.js
```

Node 18 이상이면 돼요. 테스트는 설명란 파싱, 구글 지도 화면 문구 판별, 번역 일관성(두 언어의 키 일치, 오류 코드마다 번역 존재)을 다뤄요. 구글 지도 화면 조작은 실제 화면에서 확인해야 해요.
